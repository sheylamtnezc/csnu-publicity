# Lo Que No Se Cuenta — Repositorio de Campaña

## ¿Qué es esto?
Este repositorio contiene todo lo necesario para ejecutar la campaña educativa
"Lo Que No Se Cuenta", una iniciativa 100% orgánica (sin publicidad pagada)
para difundir la web interactiva sobre violencia sexual en conflictos armados,
basada en datos e informes del Consejo de Seguridad de la ONU.

## Objetivo en una frase
Que universitarios cubanos (18-25 años) entren a la web, completen las
actividades interactivas y compartan sus resultados.

## ¿Cómo está organizado?
| Carpeta | Qué encontrarás | Cuándo abrirla |
|---|---|---|
| PRINCIPAL | Esta guía, calendario de 1 página | Siempre, antes que nada |
| ESTRATEGIA | Plan completo, mensajes clave, reglas de oro, fuentes ONU | Antes de publicar cualquier cosa |
| PIEZAS_GRAFICAS | Imágenes por día + textos listos + plantillas editables | Cada día, para publicar |
| AUDIO_PODCAST | Episodio completo, clip para IG, guion, transcripción | Jueves (día del podcast) |
| WEB_Y_ENLACES | Enlaces con UTM, árbol de la web, capturas, formulario | Al publicar y al medir |
| METRICAS_E_INFORMES | Plantilla de métricas, capturas, informe final | Diario (10 min) y domingo |
| RESPALDOS_Y_PLAN_B | Piezas ligeras, PDF offline, checklist | Si falla la conexión o el formato |

## ¿Qué abro primero según lo que necesite hacer?
- **Voy a publicar hoy** → `02_PIEZAS_GRAFICAS/[DIA]/` + `04_WEB_Y_ENLACES/ENLACES_UTM.tx6
- **Necesito revisar qué se puede decir y qué no** → `01_ESTRATEGIA/TONO_Y_REGLAS_DE_ORO.pdf`
- **No hay señal y hay que publicar igual** → `07_RESPALDOS_Y_PLAN_B/`
- **Toca medir o cerrar la semana** → `06_METRICAS_E_INFORMES/`

## Reglas básicas del repositorio
1. Los archivos se nombran así: `DIA_tipo_descripcion.ext` (ej.: `LUNES_carrusel_tarjeta01.png`).
   Sin espacios, sin acentos en nombres de archivo.
2. Cada día tiene su propio `textos_DIA.txt` con el copy exacto. No improvises el texto.
3. Si una pieza no se usó, se mueve a `07_RESPALDOS_Y_PLAN_B/` o se borra.
   El repositorio debe reflejar lo que se publicó.
4. Los colaboradores tienen solo lectura en `05_COLABORADORES/`.
   No muevan piezas maestras.
5. Respaldo semanal: al cierre del domingo, descarga el repositorio completo
   a un teléfono o USB (por si falla el acceso a Drive).
